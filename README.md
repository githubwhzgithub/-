# STM32 双轮自平衡小车控制系统

## 项目概述

本文档详细描述了基于STM32单片机的平衡车系统设计方案。平衡车系统集成多种功能模块，包括车架结构、电机驱动、姿态传感器、视觉识别等，实现了自平衡行走、避障寻迹等基本功能，并具备蓝牙远程控制、语音播报，物体识别等创新功能。并通过Android Studio为平衡车量身开发了一款蓝牙控制APP“眉峰一号”，使用户可以极为方便的操控平衡车。

项目GitHub地址：[https://github.com/githubwhzgithub/-](https://github.com/githubwhzgithub/-)

## 系统架构

平衡车系统采用模块化设计，主要由控制系统、驱动系统、传感系统和功能扩展系统组成。系统整体架构基于STM32F103C8T6微控制器，运行频率72MHz，具备64KB Flash和20KB RAM。

(见 `report/平衡车系统框图.png`)

### 主控制器
- **MCU**: STM32F103C8T6

### 控制算法

#### 1. 平衡控制 (三环级联PID)

| 控制环 | Kp | Ki | Kd | 输出限幅 |
| :--- | :--- | :--- | :--- | :--- |
| 角度环 | 42.0 | 0.0 | 1.5 | ±900 |
| 速度环 | 2000.0 | 200.0 | 0.0 | ±500 |
| 转向环 | 2.0 | 0.0 | 0.01 | ±500 |

#### 2. 卡尔曼滤波
- 融合加速度计和陀螺仪数据，实时估计车体姿态角度，滤除传感器噪声。

#### 3. 障碍物避障
- **超声波避障**: 检测距离 < 50cm时触发，立即停止前进，播报语音并执行转弯动作。
- **视觉避障/寻迹**: 通过K230视觉模块实现，支持循迹、物体追踪等模式。

### 多任务调度

系统采用基于定时器中断的多任务调度机制，确保各个功能模块的实时性和稳定性。

| 任务名称 | 频率 | 周期(ms) | 优先级 | 主要功能 |
| :--- | :--- | :--- | :--- | :--- |
| 平衡控制 | 200Hz | 5 | 最高 | PID控制、电机输出 |
| MPU6050读取 | 200Hz | 5 | 最高 | 姿态角计算 |
| 编码器更新 | 100Hz | 10 | 高 | 速度、位移计算 |
| 蓝牙通信 | 50Hz | 20 | 中 | 命令处理 |
| 超声波检测 | 20Hz | 50 | 低 | 距离测量 |
| K230视觉更新 | 50Hz | 20 | 中 | 视觉数据处理 |

## 蓝牙控制命令

| 命令 | 功能 | 参数说明 |
| :--- | :--- | :--- |
| GO | 系统启动 | 无参数 |
| FORWARD | 前进 | 可选速度值(0-1000) |
| BACKWARD | 后退 | 可选速度值(0-1000) |
| LEFT | 左转 | 可选角速度值 |
| RIGHT | 右转 | 可选角速度值 |
| STOP | 停止 | 无参数 |
| LINE | 设置循迹模式 | 无参数 |
| TRACK | 设置物体检测模式 | 无参数 |
| VISIONOFF | 关闭视觉检测 | 无参数 |
| STATUS | 状态查询 | 返回系统状态 |
| RESET | 系统复位 | 无参数 |

### 命令示例
```
START              # 启动平衡
FORWARD 0.3        # 以0.3的速度前进
SPEED 0.5          # 设置速度为0.5
PID 120.0 0.2 15.0 # 设置PID参数
STATUS             # 查询状态
STOP               # 停止平衡
```

## 编译和烧录

### 开发环境
- **IDE**: STM32CubeIDE & Keil MDK
- **HAL库**: STM32F1xx HAL Driver
- **编译器**: ARM GCC

### 编译与烧录
1. 打开项目文件 (`.uvprojx` for Keil, `.ioc` for CubeIDE)。
2. 编译项目生成 `.hex` 文件。
3. 使用 ST-Link V2 或串口进行烧录。

## 调试和测试

### 串口调试
- **USART1 (PA9/PA10)**: 用于系统调试信息输出，波特率 115200。
- **USART3 (PB10/PB11)**: 连接HC-05蓝牙模块，波特率 9600。

## 安全注意事项

1. **电源管理**: 使用12V锂电池供电。
2. **机械安全**: 确保车轮与地面良好接触，检查电机和车架固定，避免在高处测试。

## 故障排除

- **平衡车不能站立**: 检查MPU6050连接、调整PID参数、确认电机方向。
- **蓝牙无法连接**: 检查HC-05模块电源、确认波特率设置、重新配对设备。
- **编码器读数异常**: 检查编码器供电和信号线连接。
- **超声波测距不准**: 检查TRIG/ECHO连接和中断配置。
